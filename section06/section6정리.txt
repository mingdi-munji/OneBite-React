UI구성하기

블록 내부에 className="이름" 설정 후,
css내부에서 .이름 {}으로 UI를 지정한다.

----------------
App내부에서 값을 모두 공유 가능한 App에서 state를 조작해야, 
부모-자식관계
countState => Viewer 
setCount => 이벤트 핸들러로 제작 후 => Controller

부모인 APP에서 useState를 정의, viewer로의 전달을 위해 Viewer태그에 count = {count} 전달
viewer에서 전달값으로 count 가져오기, 표시 
    const viewer = ({count}) => {
        <>
            <h1> {count} </h1>
        <>
    }

    값을 전달하는 경우에는, 아래와 같이 원하는 곳에 파라미터값 자체나 함수를 중괄호로 넘겨주어야 해당 파일에서 사용가능하다.
        <Viewer count = {count}/> 
        <Controller onClickButton={onClickButton} />

    *값을 전달하는 경우에는 부모-자식관계를 가지고 있어야한다.
     props기능으로 부모 -> 자식 방향으로만 데이터 전달 가능 (단방향 데이터흐름_일방통행)
     (여러 파일에서 관리하는 경우, 컴포넌트는 공통 부모에서 관리해야된다.)

     스테이트 리프팅 _state lifting : 스테이트를 계층의 구조상에서 위로 끌어올려서 그 아래에 있는 컴포넌트 들이 모두 공유할 수 있도록 만드는 방법

     단방향으로만 전달 가능하기 때문에 기능을 구현할 때, 원천 스테이트를 어디에 위치시킬지를 잘 고려해야한다.
