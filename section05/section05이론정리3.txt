하나의 이벤트 핸들러 객체로 여러개의 useState관리하기
    하나의 useState를 생성해서 초기값을 객체 {}로 설정
        const [input,setInput] = useState({
            name :"",
            country:"",
            birth:"",
            intro:"",
        });
        const onChange = (e) => {
            setInput({
                ...input,
                [e.target.name] : e.target.value, //e.target의 name인 name,birth,country,intro를 키 값으로 value값이 저장된다.
            });
        }

    return 에서 블록 속성에 name="키값"으로 설정해야 값이 전달된다.
        <input 
            name="name"
            value = {input.name} //초깃값 
            onChange={onChange}
        />
        <input 
            name="birth" 
            value ={input.birth} 
            onChange = {onChange} 
            type="date"
        />

useRef _useReference : 컴포넌트 내부에 새로운 레퍼런스 객체를 생성해주는 기능
    => 컴포넌트 내부의 변수로써 일반적인 값들을 저장할 수 있다. (useState와 비슷)
        (어떤 경우에도 리렌더링이 되지않는 점에서 useState와 다르다.)
        포커싱 또는 요소의 스타일을 갑자기 변경에 사용 가능

    레퍼런스 객체 : Current프로퍼티에 현재 보관값을 담아두기만 하는 js객체
        해당 객체의 리렌더링 없는 작업 (현재 작업의 console.log 등)만 수행되며, 이전의 작업이 다시 실행되거나 화면상의 업데이트는 발생하지않는다.

    **레퍼런스 오브젝트 사용 상황 : 렌더링에 영향을 미치지않아야하는 변수를 생성할 떄 사용
        import {useRef} from 'react'; //임포트 필요
        const inputRef = useRef();
        const onSubmit = () => {
            if(input.name ==="") {
                //이름을 입력하는 DOM요소 포커스
                inputRef.current.focus();
            }
        }

        <input 
            ref = {inputRef}  //레퍼런스에 대한 컴포넌트 설정
            name="name"
            value = {input.name} //초깃값 
            onChange={onChange}
            placeholder="이름" //예시제공
        />
        <button onClick={onSubmit}> 제출 </button>

**레퍼런스 객체는 useState의 리렌더링에 값이 초기화 되지않는 점에서 일반변수 let,const와의 차이가 있다.
    컴포넌트 외부에 변수를 두는 경우에는, 변수가 공유되어 각각의 값을 담을 수 없기에 추천되지 않는다.

useRef관련 속성 
    focus 속성 : ref컴포넌트.current.focus(); 현재 객체에 포커스를 준다.

React Hooks : 클래스 컴포넌트의 기능을 함수 컴포넌트에서도 이용할 수 있도록 하는 메소드들
    => 함수 컴포넌트에서 클래스 컴포넌트의 기능을 낚아채와 사용 가능

    React Hooks는 리액트 내장함수로, use가 접두사로 쓰인다.
      => 각각의 메소드는 Hook이라고 부른다.
        useState (Hook)
        useRef (Hook)
        useEffect, useReducer 등
    *함수 컴포넌트 내부에서만 호출 가능, 조건부로 호출되면 x => 조건문이나 반복문에서는 호출이 불가능하다.
    use를 사용하여 커스텀 훅을 생성 가능

//3가지 hook 관련 팁
1. 함수컴포넌트, 커스텀 훅 내부에서만 호출 가능
2. 조건부(조건문,반복문 내부)로 호출될 수는 없다. => 렌더링에서 hook의 호출 순서가 꼬일 수 있다.
3. 나만의 훅(Custom Hook)을 만들 수 있다.
    함수명을 use로 시작하게 만드는 경우, react내부에서 hook으로 인지한다.
    => 반복되는 내용에 대해 커스텀 훅을 이용한 생산 가능
        커스텀 훅은 src/Hooks에 보관하는 것이 일반적

        function useInput(){
            const [input,setInput] = useState("");
            const onChange = (e) => {
                setInput(e.target.value);
            };
            return [input,onChange];
        }
        const HookExam = () => {
            const [input,onChange] = useInput();

            return (
                <>
                    <input value = {input} onChange = {onChange}/>
                    <input value = {input1} onChange = {onChange1}/>
                </>
            );
        }
