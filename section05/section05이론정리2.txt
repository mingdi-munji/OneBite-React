State : 현재 가지고 있는 형태나 모양의 정의 _변화할 수 있는 동적인 값
        (컴포넌트의 현재 상태를 보관하는 변수)
        
        stat를 사용하려면 해당 파일 상단에 import문 필요
            import {useState} from 'react';

        const [state,setState]= useState();  //첫번째 값은 초기값, 두번째값은 상태변화함수 (상태를 변화시키는 함수)
        console.log(state);  //0
        <button onClick={() => {
            setState (state+1);  //상태변화함수를 사용하여 새롭게 전달할값을 작성
        }}> + </button>

Rerendering _리렌더링 : 컴포넌트의 state값이 변경되면 새롭게 리턴 발생
        *일반적인 함수로 만드는 경우, 업데이트값이 즉각적으로 화면에 나타나지 않는다. (state필요)

    App() 외부에 state값을 props로 받는 함수를 설정, App 내부에서 props값을 받아오게 설정하여 state값에 따른 상태변화함수를 설정할 수 있다.
        const Bulbs = ({light}) => { //자식 컴포넌트
            return (
                <div> 
                    {light==="off"? (<h1>Off</h1>):(<h1>On</h1>)}
                </div>
            )
        }
        function App() { //부모 컴포넌트
            const [light,setLight] = useState("off");
            return (
                <>
                    <Bulb light = {light} />
                </>
            )
        }

    리렌더링이 진행되는 상황_3
    1. 자신이 관리하는 state의 값이 변경되는 경우
    2. 제공받는 props의 값이 변경되는 경우
    3. 부모 컴포넌트가 리렌더링 되는 경우
        부모 내부에 여러 컴포넌트가 있는 경우, 렌더링으로 인한 성능 저하 발생 
        => 서로 다른 컴포넌트로 분리하는 것이 좋다.
