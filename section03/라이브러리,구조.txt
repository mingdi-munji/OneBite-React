라이브러리 설치 : npmjs 사이트에서 가능
설치하면 node_modules 폴더 생성됨 => 실제 설치된 라이브러리의 저장소
 package-lock.json 파일 생성됨 => package.json의 상세버전
 
 라이브러리를 사용하는 경우, import randomColor from "randomcolor"; 처럼 라이브러리 명칭만으로도 접근 가능

 *node_module 또는 package-lock.json이 삭제된 경우, npm i를 통해 package.json의 dependencies를 통한 라이브러리 재설치가 가능하다.
  ==> 배포하는 경우, node_module와 package-lock 파일은 업로드하지 않아도된다.
