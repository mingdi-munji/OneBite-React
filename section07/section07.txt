### 리엑트 컴포넌트의 라이프 사이클 : Mount -> Update -> UnMount
    Mount : 컴포넌트가 처음 렌더링 되는 순간을 의미 
    Update : 컴포넌트가 다시 렌더링 되는 순간 (리렌더링)
    UnMount : 컴포넌트가 화면에서 사라지는 순간 (렌더링에서 제외)
 *라이플사이클 제어 : 라이프사이클의 단계별로 컴포넌트들이 각각 다른 작업을 수행하도록 만든 것
   => useEffect를 사용하여 구현

### useEffect (리엑트 훅)
    useEffect : 컴포넌트의 사이드 이펙트를 제어하는 새로운 리엑트 훅
    
        import {useState,useEffect} from "react";
        const [count,setCount] = useState(0)
        useEffect ( () => {
            console.log(`count : ${count}/ input : ${input}`);
        }, [count,input]);

            //두번째 인수인 배열에 들어간 값이 바뀌면 첫번째 인수의 콜백함수를 실행
            ==> 의존성 배열 dependency array (deps)
                (배열에 따라 다른 동작을 하기 때문)

        <input value={count} onChange={(e)=> {
            setCount(e.target.value);
        }}/>

        실제 인스턴스에 console.log를 사용하는 경우,
        리엑트의 상태변수합수는 비동기로 작동하기 때문에 정확하지않은값 (변경 이전의 값)이 출력되는 위험이 있다.

### Mount / Update / Unmount 코드로 설명하기
    1. Mount : 탄생
     useEffect(()=> {console.log("mount")}, []); //빈 배열로 처음 랜더링 시에만 값이 바뀌게 설정

    2. Update : 변화, 리렌더링
     2.1 _첫렌더링을 포함하여 모든 렌더링 시에 실행 (useEffect)
     useEffect(()=> {console.log("update")}); //배열을 설정하지 않음 -> 모든 상황에서 값이 바뀌게 설정
     2.2 _ (useRef)

    3. Unmount : 죽음
    //전체적인 구조: 빈배열 useEffect 로 마운트 될 때 실행 , unMount 될때 종료되는 함수
     useEffect(()=> { //
        return () => {
            console.log("unMount");
        };
     } ,[]); 

     콜백함수가 반환하는 함수 == 클린업함수 (정리함수) 
     이는 useEffect가 끝날때 unMount될 때 실행된다.
